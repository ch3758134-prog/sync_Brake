# Driver 模板设计讨论记录（待决，不是接口规范）

当前工作只完成嵌入式工程模板。不在此文档里擅自决定新的 GPIO、CAN、UART 或 DMA API。

下一阶段讨论需要的事实和问题：

1. **SDK 依据**：对应版本的 YTM32B1LE0 官方 SDK、具体外设头文件/示例，哪些已实现，哪些未提供？
2. **功能边界**：哪些外设直接使用官方 SDK 就足够？哪些确实需要跨 MCU 公共接口？
3. **启动与配置**：时钟源、引脚、UART/CAN 参数、DMA 资源来源于哪里？YCT 与真实 PCB 怎么对应？
4. **执行上下文**：驱动是否使用 ISR、DMA 完成回调、主循环轮询？中断由谁唯一拥有？
5. **数据合同**：接收/发送是同步还是异步，缓冲区生命周期、队列容量、溢出和错误返回如何定义？
6. **异常恢复**：初始化失败、总线故障、通讯中断、系统复位时的状态、恢复限制是什么？
7. **验证方法**：每个模块的 `tests/target/test_xxx.c/h` 和 Host 测试如何组织与保留？
8. **安全约束**：所有未获授权的真实制动输出必须保持禁止状态，不能为了做驱动实验绕过保护。

等我们讨论完，才决定 Driver 文件形式、API 和对应 Keil 源文件；不能拿旧候审头文件自动当作正式模板。
