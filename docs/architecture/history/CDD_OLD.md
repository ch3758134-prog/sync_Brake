# CDD｜专用设备驱动（按真实硬件逐项实施）

CDD 为当前项目的专用驱动区，不等同于“复杂就必须放 CDD”。

- BMA510：核对实物 I²C/SPI、电气接口、标定/时间戳和芯片官方文档后才实现。
- WLT8016：只处理真实模块的串口协议、连接/配置及设备错误；不得更改制动运行许可。
- 外置 CAN 加速度模块：独立于 MCU CAN 控制器，核对真实 ID/报文格式/单位/时效后实现。

CDD 可调用 MCAL 稳定总线接口和 Services，不可以直接调用 ASW 制动算法。
目前没有可信的实际设备总线/协议实现，**不创建空壳 .c**。此目录不是 AUTOSAR 合规声明。
