# BrakeSync｜文档、制品与工程任务交接控制规程

**编号**：BS-CM-PROC-001 · **日期**：2026-11-14 · **状态**：项目负责人当前指令下启用的交付控制规则。

## 1. 单一真相源

- 项目正式需求、设计、接口合同、审批记录、开发环境文档、测试证据、交接清单应以 GitHub 可追踪版本为准。**本对话附件不是长期受控仓库**。
- 统一管理索引位于 [00_INDEX.md](./00_INDEX.md)；交付注册位于 [02_ARTIFACT_REGISTER.md](./02_ARTIFACT_REGISTER.md)；当前执行工作台位于 [execution/ACTIVE_WORK.md](../execution/ACTIVE_WORK.md)。
- `management` 存放批准基线、管理工作稿、交接与安全/质量证据；`firmware`、`app` 用于经过单独授权的真实研发源码。不能把管理分支中的候选模板当作已落地的正式固件。
- 重要外部原始资料（厂商 SDK、PDF、客户资料等）如有许可、商业敏感或版权限制，须改存受控来源；公开 GitHub 只放登记、版本/哈希、许可状态及访问责任。当前仓库为公开仓库。

## 2. 责任与交接矩阵

项目目前只有一位实际人类负责人，责任落实为**角色与明确的唯一人类责任方**；AI 可以承担执行任务，但不取代企业真实签收与审批。

| 工作对象 | 最终责任 A/DRI | 制作/执行 R | 核查/咨询 C | 实际接收/验收 |
|---|---|---|---|---|
| 产品与安全基线 | 项目负责人 | ChatGPT 编写/核对 | 供应商资料、必要专业审核人（尚未落实） | 项目负责人 |
| MCU C 驱动和新 Target 工程 | 项目负责人 | Codex（批准任务后），用户完成实板操作 | ChatGPT 设计、代码审查 | 项目负责人 |
| 编译/静态检查/Host 证据 | 项目负责人 | 执行者（Codex/工具） | ChatGPT 复核 | 项目负责人 |
| 硬件接线/电流/波形/台架/车辆测试 | 项目负责人 | 实际执行者，需具备适用资质/设施 | 安全评审和硬件依据 | 项目负责人 |
| GitHub 管理文档/交接索引 | 项目负责人 | ChatGPT（当前已获授权的 `management` 范围） | 自动文件审计/人工核对 | 项目负责人 |
| 供应商受限文档 | 项目负责人 | 被授权的资料保管者（当前为负责人） | 法律/供应商许可 | 有授权的研发执行者 |

## 3. 每项交付物的必填字段

`Artifact-ID`, `Work-Package-ID`, `title`, `version`, `source_version`, `status`, `GitHub_PATH` 或受控资料仓库路径, `SHA256/Git_Blob`, `DRI`, `producer`, `receiver`, `date`, `acceptance_criteria`, `test_level`, `open_issues`, `handover_record`。

无真实证据填写 `NOT_RUN`，缺物理信息 `OPEN/BLOCKED`，未核验外部资料填写 `RESTRICTED`，**不得留空却标记完成**。

## 4. 生命周期和质量门禁

`DRAFT → IN_REVIEW → APPROVED (仅审批范围) → ARCHIVED → SUBMITTED_FOR_HANDOVER → ACCEPTED`

- `APPROVED` 只代表需求/设计/规程获批；不代表编译/烧录/实测或安全符合。
- `ARCHIVED` 必须有实际 GitHub 提交及二次读取核对；仅生成本地 `.md`、ZIP 或对话附件不算入库。
- `ACCEPTED` 必须有接收方确认、文件可取得、完整性/版本与要求检查、未决问题可追踪；不能仅由上传者自评。
- 运行级别必须区分：文档评审、Host Build、Target Build、烧录、板上运行、实际模块、受控功率、车辆工况、产品安全/交付验收。
- 重要变更：提交新版本、差异和影响分析，关联旧版本；旧批准文档只读保留。
- 对第三方原件与二进制保留来源、许可、校验值；公开 GitHub 不可代替合法供应商资料受控保管区。

## 5. 每次 AI/Codex 工作的交接输出

执行者交付一个 Markdown `HANDOVER.md`：目标和范围、明确文件列表、代码及文档提交 SHA、原始测试命令/日志、环境版本、已知问题、未测项、风险、回滚方案、接收人、验收结论。**Codex 不在任务范围外重新设计架构**；ChatGPT 审核设计和结果；项目负责人进行实际验收。

禁止“附件留在聊天里、以后再补 GitHub”；任务结束前必须完成上传、复核或创建具名阻断记录。每次提交后核对 `git ls-tree`/GitHub Tree 清单和关键文件 Blob SHA。
