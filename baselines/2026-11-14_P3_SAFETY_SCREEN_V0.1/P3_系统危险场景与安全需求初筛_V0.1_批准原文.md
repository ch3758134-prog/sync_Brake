# BrakeSync｜P3 系统危险场景与安全需求初筛 V0.1

**文档编号：** `BS-P3-SAFE-001`  
**版本 / 日期：** V0.1 / 2026-11-13  
**审批状态：** `DRAFT_FOR_OWNER_REVIEW`，本对话交付；未获审批、未归档为正式要求  
**上游基线：** P0–P8 全阶段方案 V0.1、P3《系统功能分配与产品边界 V0.2》及《产品适用边界与性能需求 V0.1》，均已由负责人批准  
**分析层级：** 整机/系统使用风险与安全需求初筛，不是固件详细设计，不是 HARA 或产品合规鉴定。

## 0. 结论摘要

1. **BrakeSync 控制的是拖挂车的制动作用，不是普通舒适性执行器。** 即使仅“过早、过强或迟滞”而不是完全失效，也可能影响拖挂组合的方向稳定性和制动距离。
2. 初期必须同时分析两大危害：**未经期望的拖挂制动**与**期望制动未被有效提供**。不能仅把“所有异常立即输出零”当作普适安全要求；在牵引车正制动、拖挂已施加制动等不同场景，后果可能不同。
3. 必须另外分析**制动无法释放、左右/轴间制动力不均、错误配置、驾驶员误判状态、安装/线束错误、供电瞬变和无线/人机交互意外影响控制**。
4. 控制软件只能承担其可以观测、判断和限制的部分。**功率执行禁止路径、电气保护、上电默认态、线束保护、制动器热/电限值、独立故障处理**必须交给实际硬件与系统集成联合验证。
5. 当前唯一已经获准的实验边界是：**开发板上不连接真实拖挂制动功率执行链**。任何后续实体制动输出，都需要独立设计审查和试验准入，不被本稿批准所包含。

## 1. 分析范围与明确假设

| 项目 | 当前依据或假设 | 工程处理 |
|---|---|---|
| 目标对象 | 首版优先电控制动器拖挂房车；实际类型、质量、轴数未确认 | 初筛覆盖电磁制动执行系统，数值和拓扑保留开放 |
| 控制意图 | 牵引车制动相关输入 + 运动信息等形成拖挂制动逻辑请求 | 该输入组合仍是逻辑定义，不指定传感器、车辆总线或具体算法 |
| 主控边界 | 主机独立执行必要的自动制动判断 | 手机、LCD 不得成为实时制动链必需条件 |
| 输出边界 | 后续有功率级和轮端制动器，当前无已批准最终硬件 | 输出失控需系统级保护；不得仅凭软件停 PWM 宣称安全 |
| 车辆工作条件 | 正常拖曳、制动中、坡道、转向、低附着、倒车、停车等 | 风险初筛覆盖工况，是否属于目标产品适用范围待定 |
| 制动器独立应急装置 | 可能存在拖挂脱离后的应急制动/驻车或其他法规要求 | 不假定 BrakeSync 对其拥有控制权；必须研究实际安装系统与法规 |
| 法规和市场 | 目标销售地域、车辆类别未定 | 不做符合性声明，不给定法规阈值或 ASIL 等级 |

### 关键术语

- **危险场景（Hazardous event）**：在某种运行环境下，系统行为或功能失效可能导致车辆/人员伤害的场景。
- **失效模式**：具体功能、电气或机械行为异常，例如输出粘连、信号方向错误。失效模式不等于危险结论，必须放回车辆工况判断。
- **安全目标（SG）**：为避免或控制危险而提出的系统层目标。本稿均为 `CANDIDATE`。
- **安全状态**：在相应危险和工况下，经分析证明有助于控制风险的系统反应；不能在没有证据时一律等同“关断”或“持续制动”。

## 2. 系统危险场景初筛（HA-01～HA-12）

| ID | 危险场景及工况 | 可能失效/误用源（例示） | 潜在后果 | 需要定义的风险控制方向 |
|---|---|---|---|---|
| HA-01 | 车辆未要求制动时，拖挂突然施加制动，尤其在高速、转弯或低附着路面 | 输入误识别、参数损坏、执行器异常、误授权写入 | 拖挂甩尾/偏航、失稳、追尾风险 | 意图确认、输出权限、异常输出检测、执行独立保护 |
| HA-02 | 牵引车制动时，拖挂未达到其应有制动作用 | 信号丢失、传感数据过期、电源故障、执行器断路 | 组合制动距离增加、牵引车承载异常 | 可用性监测、故障识别、驾驶员警示、工况化失效处理 |
| HA-03 | 拖挂制动力明显过强，尤其低附着或空载拖挂 | 档位/映射错误、控制输出失控、用户错误配置 | 拖挂车轮抱死、方向失稳、轮胎损伤 | 参数范围/合法性、受限输出、工况与标定验证 |
| HA-04 | 拖挂制动力明显过弱或响应迟缓 | 输入/运动信号滞后、执行器能力不足、功率热降额 | 拖挂推挤牵引车、制动距离增加 | 端到端响应预算、能力限制与可观测故障 |
| HA-05 | 驾驶员松开制动后，拖挂制动力未及时释放 | 控制状态卡住、输出晶体管短路、继电器/电路故障 | 拖拽、过热、轮胎损伤、失稳 | 输出释放监测、独立切断能力和热保护依据 |
| HA-06 | 左右轮或不同轴制动力异常不一致 | 线束开路、轮端线圈差异、功率通道不均、机械磨损 | 牵引组合偏航、制动效率不均 | 通道配置/监测能力需求和维修检查要求 |
| HA-07 | 车载上电、复位、看门狗、棕断期间产生脉冲或未定义制动 | 复位引脚浮空、功率驱动默认态不受控、启动毛刺 | 未预期车辆减速度或静止起步冲击 | 电气默认态、复位时序、输出物理禁止、上电复测 |
| HA-08 | 供电反接、浪涌、瞬态跌落、电气短路使制动异常 | 线束故障、电池/牵引车供电瞬变、功率器件短路 | HA-01/02/05 类危险并可伴随热损伤 | 电源/线束保护、热/过流、电气耐受与诊断 |
| HA-09 | 运动方向、单位或安装方向错误导致控制方向/幅值错误 | 传感安装反向、坐标配置错误、量纲换算错误 | 意外或不足制动 | 安装校核、方向/单位合同、不可用数据拒收 |
| HA-10 | 用户在不适宜工况修改重量档或制动力，或者非法/重复无线命令生效 | App 连接误认、无确认变更、授权漏洞、重放与异常重连 | 控制行为突然变化、驾驶员预期与设备不一致 | 操作权限/工况门控、事务回执、变更时机与状态提示 |
| HA-11 | 系统失效但对用户呈现“正常”，或提示内容与设备真实状态不一致 | UI 缓存、断链、诊断丢失、指示灯/显示异常 | 驾驶员继续依赖不可用制动，延误检查 | 健康状态源、时间有效性、明确区分通信断开与设备正常 |
| HA-12 | 脱挂、驻车、倒车、坡道及维护工况中与其他制动系统互相干扰 | 线束/接口错接、未定义的应急制动边界、误启用特殊模式 | 未期望车辆运动、制动力冲突或失效 | 明确系统集成边界、安装前提、应急制动独立性和维修隔离 |

**说明：** 以上是一份**待分类的初始危险场景库**；不代表已经判断概率、严重性、可控性或实现了任何安全机制。某项危险可能由多个原因共同触发，也可能需要多个独立保护措施。

在市场、制动器、功率硬件尚未定型时，下列要求只作为**不可遗漏的设计题目和验证方向**，不能当作数值已经确定的可执行详细规格。

## 5. 不能由软件单独宣称满足的安全要求

| 主题 | 主控系统可能负责的部分 | 仍必须由硬件/安装/整车验证承担的部分 |
|---|---|---|
| 无意输出 | 决策许可、状态、输出命令检查 | 功率器件短路、上电高阻、安全禁止电路、引脚错接 |
| 无法释放 | 控制请求撤销、状态诊断 | 实际电流测量、功率级断开、轮端机械拖滞 |
| 制动力不足 | 输入质量、请求范围、故障报告 | 线圈/制动器能力、连接损耗、摩擦/热衰退、附着条件 |
| 输出不均衡 | 对可见通道异常的诊断与限制 | 左右/轴间实际电流和机械制动力差异、布线与安装 |
| 电源干扰 | 欠压/重启状态识别 | 供电保护、瞬态、EMC/ESD、散热、熔断路径 |
| 用户提示 | 故障状态语义、过期状态识别 | 人机安装位置、可见性、驾驶员分心及失效时可观察性 |

**工程判据：** 安全需求的“责任分配”必须能落到可验证的系统元素和测试证据。不能把尚不存在的执行硬件安全路径记成软件模块“已实现”。
