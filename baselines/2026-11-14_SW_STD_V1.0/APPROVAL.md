# BrakeSync｜BS-SW-STD-001 V1.0 正式批准记录

**日期：** 2026-11-14  
**文件编号：** `BS-SW-STD-001`  
**审批状态：** `APPROVED_AS_MANDATORY_PROCESS_BASELINE`  
**批准依据：** 项目负责人在审阅《汽车电子软件工程与 C 编码强制规范 V1.0》及新工程严格质量门禁模板后，明确回复“可以，批准”。

## 本次批准的有效内容

1. [汽车电子软件工程与 C 编码强制规范 V1.0 原文](./BS-SW-STD-001_V1.0_批准原文.md) 成为 BrakeSync 新固件、ASW/BSW/驱动、设备协议、构建系统和测试的**强制工程质量基线**。文件原文保留其提交前 `PROPOSED_FOR_PROJECT_ADOPTION` 历史字样，批准状态以本审批记录为准。
2. 严格参考 MISRA C:2025、ISO 26262:2018、Automotive SPICE 4.1、ISO/SAE 21434:2021，以及相关适用更新与工具链要求，执行分层设计、编码、证据追踪、专业静态检查、偏离管理、代码审查、功能/异常测试和质量门禁。
3. 按 **SW-00 环境/芯片/SDK/工具链/板型核验 → SW-01 新建受控云途 Target 工程并完成编译烧录调试 → SW-02及后续逐驱动开发与测试**的路径推进。正式 PCB 未完成不阻止开发板上的隔离、无真实制动功率的前期研发。
4. 本轮新固件模板 V0.2 仍是**本对话交付的本地源码候选**；不得把该模板存在或 Host 编译成功等同于 MCU Target 工程、外设驱动或汽车软件规范符合性已完成。
5. 已批准的 `BS-P0P8-BASELINE-003 / V0.3` 继续有效，版本顺序保持 **V1真实功能测试 → V2 LCD完整交付 → V3 App**。

## 未获得本次批准的事项

- **没有**授权具体源码文件修改、推送到 `main`/`firmware`/`app` 分支或清理/复用旧代码。
- **没有**确认特定云途 YCT/SDK/编译器、板卡 Revision、调试器和真实外接模块已经完成 SW-00 核验。
- **没有**宣布 MISRA 全规则专业检查通过、ISO 26262 安全合规、ASPICE 评估通过、ASIL 等级、安全认证、任何实物制动功能通过或正式产品发布。
- **没有**授权开发板连接真实拖挂制动功率链；以后涉及实体输出仍需独立硬件、安全与受控台架准入。

## 下一步唯一执行入口

`execution/ACTIVE_WORK.md` 为当前可查看的管理工作台。优先补齐 SW-00 中的客观开发板与工具链事实；环境核验后按 SW-01 受控建立全新 Target 工程，不复制旧固件工程，也不把既有旧源码算作完成。
