## 0. 发布不是代码合并

P8 的对象是**经过真实验收的确定产品/研发交付包**，而不是某一分支存在文件。当前 BrakeSync 尚无可交付量产制动产品、目标整机 PCB 和系统级通过证据。本文件给出开发板研究包与未来产品发布的严格分级、发布内容、审批和维护交接流程；**不代表当前任何正式产品发布已批准**。

## 1. 发布对象分级

| 类别 | 交付对象 | 可以被承认的范围 | 必须标注的限制 |
|---|---|---|---|
| `EVB-RESEARCH` | 开发板研究/通信功能包 | 同一板+模块组合的 SDK 适配、CAN/BLE/传感器演示与独立测试 | 不是实际制动器；真实功率输出禁止；仅按实测子项称通过 |
| `FW-INTERNAL` | Host/Target 软件里程碑 | 可追溯 C 源码、SDK、接口、测试和已知问题 | 未经完整产品验证，不得作为装车软件 |
| `APP-INTERNAL` | 手机 App 内部测试版 | 指定手机系统/协议下功能和异常测试 | Mock 与真实设备清楚区分，不许虚构已联调 |
| `SYSTEM-PROTOTYPE` | 未来完整样机 | 指定硬件/BOM/固件/App 组合及指定台架能力 | 不等于量产/道路许可，残余风险明确 |
| `PRODUCT-RELEASE` | 目标市场正式产品 | 具体型号、配置、使用场景、已核准验收和法规/安全符合性证据 | 当前**不具备发布条件** |

发布 `EVB-RESEARCH` 也需要明确授权和版本登记；它不能解除功率输出禁令。

`Variant`、`Board`、`Release` 三者独立记录；不得将开发板硬件资料写进所有产品 Variant，也不得仅因发布号增加就认为软硬件兼容。

## 3. 交付包清单（与具体范围匹配）

| 条目 | EVB 研究包 | 未来正式产品包 | 准入原则 |
|---|---|---|---|
| 源码与变更摘要 | 必须 | 必须 | SHA、差异、许可记录明确 |
| 编译工具链/SDK 及依赖版本 | 必须 | 必须 | 不在公开仓库上传未经授权 SDK/手册 |
| Board/Variant/Release 清单 | 必须 | 必须 | 实物 Rev 和配置可核对 |
| 原始 CI/模块测试记录 | 必须 | 必须 | 测试范围与结论一致 |
| 目标烧录、运行与模块日志 | 适用时必须 | 必须 | Host 不替代 Target |

## 4. 发布与维护交接

1. **冻结候选范围**：填写具体产品/研究对象、受控源版本、用户和目标硬件；
2. **审查证据**：编译、测试、实物、风险和缺陷逐项对应实际记录；
3. **确认分发权限**：第三方芯片手册、云途保密文档、SDK、开源许可证和其他资料必须按授权传播；
4. **评审兼容性**：固件/App 协议、参数存储版本、硬件修订和迁移/回滚依据；
5. **单独获得正式发布批准**：本 AI 不能代表负责人签发；
6. **记录交付和接收**：发布包 SHA、交付范围、接收人、遗留风险、缺陷反馈机制；
7. **进入维护闭环**：监控故障，需求/设计受影响时做局部变更分析和回归，不反复推翻有效基线。

## 5. 常见阻断事项

| 阻断情形 | 正确处理 |
|---|---|
| CI 成功但没有 Target Build | 只承认 CI 成功，不发布需 Target 的固件 |
| 烧录成功但 CAN/蓝牙不稳定 | 保留实测失败与复现步骤；相关模块不验收 |
| 蓝牙协议双方实现不一致 | 退回统一 ICD，不让一端偷偷改变协议 |
| 已有试验板但没有故障安全通路 | 不宣布实际制动功能可以装车 |
| 仅依据历史六档/Mock 三档推出最终产品映射 | 停止量产配置冻结，取得产品/标定决定 |
| 供应商资料带 Confidential 标记而仓库为 public | 索引/校验值可登记，PDF/SDK 原件须按许可存储 |
| 找不到发布包的准确 SHA/构建依赖 | 禁止发放“不可复现的正式版本” |
