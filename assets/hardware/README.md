## 来源与工程适用范围

1. `SCH_YTM32B1LE0_EVB_Q64_RevC.pdf`：云途 YTM32B1LE0 EVB Q64 **RevC** 电路原理图，共 5 页。标有 `YTM32B1LE05H0VLHT` 和新芯片/变更提示；与用户实物的 PCB revision 仍需核对。
2. `YTM32B1LE0-EVB-LQFP64评估板参考手册.pdf`：评估板参考手册编号 `RM-YTM32B1LE0-Q64-EVB-REVA`、版本 V1.0（2022-10-14），**RevA**。不可直接把其 MCU I2C 通道定义套用至 RevC 原理图。
3. `BST-BMA510-DS000-03.PDF`：Bosch BMA510 芯片数据手册，文档号 `BST-BMA510-DS000-03`，共 174 页。尚未以实物确认用户加速度计模块就是 BMA510，也未确认其与云途 EVB 的接线。

原始 PDF 继续保留在负责人已提供的 ChatGPT 项目资料环境；该位置**不属于 GitHub 仓库，也不能假定为任何开发 AI 的自动可访问文件路径**。文件名称和 SHA-256 可用于后续授权后导入私有受控资料库，校对是否为同一版本。

## 待补充的最小证据

- 实物 PCB 板号 / 修订版丝印与 RevC 原理图适配关系；
- 蓝牙、加速度模块**实物铭牌型号、供电电平、接口、模块板级连接图**；模块是否 WLT8016 / BMA510 尚未通过实物证实；
- 芯片修订版、对应 YTMicro 官方 SDK 及可复现目标构建/外设实测记录；
- 完整原件的合法存储位置与公开分发权限（必要时使用私有仓库）。

**版本边界：** 仅为 P1 资产事实索引；不批准 P1、BLE 协议、固件修改或真实制动输出。
