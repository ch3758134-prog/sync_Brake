# 云途 Target 接入（未完成，不是假驱动）

已知资料：YTM32B1LE0-EVB-LQFP64 评估板用户手册/原理图、YTM32B1MD2x 和 YTM32B1ME0x DS（具体目标型号需由实物选择）。

1. 固定 **准确型号 + SDK 版本和散列**，在文档中记录。
2. 保留 SDK 官方目录、时钟、PINMUX、启动文件、链接脚本与中断入口，不手写猜测寄存器。
3. 在 Board 层实现 `BsPort` 的 GPIO/CAN/Timer/UART/I2C 函数指针，先进行纯通信测试。
4. UART RX DMA / 中断由实际 SDK 接口决定，驱动必须处理环缓冲区溢出/错误/超时。
5. CAN 驱动需落实 ID 过滤、总线关闭、错误计数、恢复策略与收发缓冲；当前接口仅 Classic CAN。
6. **在供电、上电禁能、硬件关断通道、看门狗和故障注入验证通过前，没有制动输出绑定 API。**
7. Board 头文件和 SDK 源码不直接透给 ASW。
