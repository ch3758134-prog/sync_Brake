# App ↔ 固件 BLE 接口合同（待定）

当前 WLT8016 F1_15 Rev2.1 提供模块电气参数与 UART 引脚信息，但没有定义：
- 产品固件 UART 默认波特率、数据位、校验位、最大吞吐量
- AT 指令语法、命令模式与透传模式切换时序
- BLE Service / Characteristic UUID、通知属性、写入方式与 MTU
- 加密配对、设备身份校验及防重放策略
- 应用层请求/应答协议、命令回执与序列号
- 蓝牙断线、重连、超时及制动失效策略

**任一关键值未确认前禁止对真实制动设备发送设置命令。**

建议以后建立版本化的共同协议规范（例如 `BLE-ICD-001`），作为两个平行分支的共同发布依据；不得让 App 或固件单方面定义而声称双方已一致。
