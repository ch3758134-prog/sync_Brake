# BrakeSync｜当前唯一执行基线

> **当前有效总体研发方案**：[`BS-P0P8-BASELINE-003 / V0.3`](../baselines/2026-11-14_P0P8_V0.3/APPROVAL.md)，2026-11-14 已获负责人一次性批准。  
> **交付格式**：仅 Markdown（`.md`），在本对话交付和审阅。GitHub `management` 用于归档。  
> **旧基线**：P0–P8 V0.2 作为历史，非冲突需求、系统合同和安全门槛仍有效；新版本路线及当前研发深度以 V0.3 为准。

## 一、产品顺序与实际进度

| 产品路线 | 目的 | 当前状态 |
|---|---|---|
| **V1 / R-TEST** | 制动意图、运动/传感、主控制、受控执行及相关模块的真实功能测试 | **未完成**；PCB 尚未设计完成，当前只能开展框架与适用的无功率验证 |
| **V2 / R-LCD** | 先实现研究资料中的 LCD 核心产品能力，再通过测试、需求补充与修订形成首个正式交付版 | **未开发完成、未交付** |
| **V3 / R-APP** | 复用成熟制动核心，后续开发 BLE/手机 App 产品形态 | **尚未进入正式产品开发** |

**P0–P8 是研发阶段，不是以上三个产品版本**；各产品版本按需经过相应实现、集成、验证、发布阶段。

## 二、当前工作：框架准备阶段

| ID | 输出 | 约束 |
|---|---|---|
| SYS-CORE | 三版共用制动功能、状态、参数与安全责任边界 | 不依赖具体 MCU 寄存器或旧源码 |
| SYS-REL | V1/V2/V3 三版功能与要求追踪矩阵 | App 不与 LCD 同期首发 |
| SYS-LCD | 根据 V1.1/V2.6/V3 建立 LCD 核心/候选/排除功能及验证矩阵 | 可选高级功能不直接变成必做 |
| SYS-PCB | 正式 PCB 设计输入：供电、制动输入、传感、执行、保护、诊断/HMI 与测试接口需求 | 实际器件/范围待真实依据，不能杜撰 |
| SYS-VAL | V1 真实模块功能测试与后续安全准入计划 | 禁止把 Host/Mock 当作 Target/台架实测 |
| SYS-PROD | 市场、车型、质量/轴数、制动器、供电等集中取舍与证据 | 尚未冻结产品实物数值 |

## 三、非混淆性约束

- **旧 GitHub `firmware`/`app` 代码不作为研发基线**；在实施阶段由负责人另行决定清理与参考复用。
- **PCB 尚未完成**；云途 EVB 仅为研究平台，暂不接入真实拖挂制动功率链。
- P0–P8 V0.3 通过是**方案批准**；没有新的 P5 Target Build/烧录、真实模块联调、P6 实物集成、P7 真实车辆验证或 P8 产品发布通过证据。
- 重大产品决定及真实制动执行安全准入仍需审批，普通 P 阶段专题不再拆开逐项审批。
