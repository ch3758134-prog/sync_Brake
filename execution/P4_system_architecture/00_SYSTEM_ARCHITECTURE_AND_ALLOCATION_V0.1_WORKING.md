## 0. 总结：这次设计解决什么

**已批准的架构原则**来自 P3 功能分配 V0.2、P3 产品适用边界 V0.1、P3 危险初筛 V0.1、P0–P8 V0.3、P4 DD-01～08 V0.2。本文把这些原则转成**系统产品设计、软硬件责任与未来 PCB 输入**。本文新提出的技术分配为候选，未自动获批。

**当前核心结论**：
1. 主 ECU 是独立同步制动决策主体。LCD、BLE/App 仅提供受控设置和状态，不成为实时制动条件。
2. 车辆制动意图与运动信息为不同物理来源和不同业务证据，不能相互冒充。
3. 逻辑制动请求、执行许可、功率驱动、实际电气反馈、轮端制动效果是五个不同事实。
4. 供电、输入保护、功率执行、失控默认态和实际故障关断不可能只靠软件自证；产品电路设计必须承担并验证具体物理责任。
5. MCU/总线/传感器路径是技术实现的**候选选项**；未确认实物前不冻结芯片引脚、通信帧或功率拓扑。
6. 第一版是**真实模块基础功能测试版**（包括将来满足安全准入的实体执行验证），第二版才是 LCD 完整产品交付版，第三版是 App 智能版。
7. 当前 PCB 尚未完成，不意味着停止系统设计，但不能以开发板的“驱动可跑”证明制动器可安全执行。

## 4. 系统运行模式：外部可观察行为，不下沉软件状态机

| 模式（系统语义） | 外部用户/测试者能看到 | 禁止混淆的情况 | 尚待系统分析 |
|---|---|---|---|
| 上电/检查中 | 正在自检、配置与连接可用性尚未确认 | 不能报正常就绪或允许功率 | 上电测量与持续时间 |
| 不具备资格 | 给出限制原因、可能的异常提示 | 不是“驱动坏了”，也不是所有故障等价 | 资格与可恢复条件 |
| 已就绪 | 必要输入/配置/诊断满足**逻辑就绪** | 不代表功率级已经安全许可 | 真实执行条件 |
| 正常同步制动活动 | 可追踪制动请求变化及因果 | 不代表真实轮端已产生预期力矩 | 动态响应/闭环验证 |
| 限制运行 | 告知能力限制及其原因 | 不自动意味着还能提供多少真实制动 | 车辆危险分析 |
| 故障/维修 | 可见故障、维护原因和复核要求 | 不让操作界面/维护命令绕过安全条件 | 锁存/恢复/授权 |
| 交互离线 | LCD/App/诊断链路不可用或数据过期 | 不代表主 ECU 自动失效或安全正常 | 失联提示与用户使用要求 |

本表用于整机行为说明，**不定义 C 枚举、任务调度、具体状态转移时序或实体失效动作**；旧 P4 DD-04 七类状态名称仍是软件设计候选的上游依据。

## 5. 故障源→系统责任→实物验证分配

| 故障族 | 检测责任候选 | 后果分析必须由谁完成 | 实物验证层级与缺口 |
|---|---|---|---|
| 输入开短路/干扰/反接 | 输入保护电路+ECU质量/诊断 | 系统安全+目标安装分析 | 开发板无功率输入/模拟源；真实线束待选 |
| 传感器失联、错向、过期 | 传感设备+ECU质量/诊断 | 系统控制/安全 | 真实模块/安装；型号未定 |
| 电源浪涌、跌落、反接 | 电源保护/复位监测+ECU | 硬件/系统安全 | 供电平台及目标环境待定 |
| 配置损坏/不适用 | ECU校验/身份/NVM | 产品标定/系统安全 | Host与未来Target存储验证；范围待定 |
| 输出开短路、过热、器件卡死 | 功率级故障机制+ECU观测 | **硬件/系统/车辆联合责任** | 专用台架 **BLOCKED** |
| 输出真实效果不足或不均 | 功率监测+轮端/车辆实测 | 产品性能/车辆安全 | 轮端电制动器与车型 **BLOCKED** |
| LCD故障或 BLE断链 | HMI连接监测+ECU自身诊断 | 人因/交互安全 | V2/V3 分版测试 |
| 脱挂、驻车、倒车与维修干涉 | 安装规则、必要硬件和ECU诊断 | **目标整车系统安全** | 市场法规/车辆安装证据 **BLOCKED** |

> 故障后的物理执行策略由**适用工况**和真实危险分析确定；不存在已批准的通用“故障全部立即断电”策略。不能因软件或硬件某一部分实现就宣布整机安全闭环完成。

## 6. V1 / V2 / V3：设计冻结与验证深度按产品版本区分

| 交付对象 | V1真实功能测试版 | V2 LCD首个完整交付版 | V3 App产品版 |

| 制动器与功率硬件 | V1达成完整真实功能目标时必须具备**已安全准入的实体执行证据** | 必须达到目标产品交付的制动器/车辆/法规与质量门槛 | 对新增无线影响及产品回归重新验证 |

| 发布 | 内部测试发布，**不代表道路产品许可** | 首个完整交付版本，经实际产品验证 | 后续智能版，受版本兼容与网络安全要求 |
