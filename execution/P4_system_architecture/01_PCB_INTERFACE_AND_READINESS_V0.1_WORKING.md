本文件将已批准的 P3 产品适用范围、KPI-01～13、HA/SG/SSR 安全初筛和 P4 系统合同，组织成**未来原理图设计启动前的工程输入检查表**，不是可直接下单的硬件设计。所有电压、电流、线径、散热、电路器件、引脚/网络名、抗扰度数值、CAN波特率、PWM频率和正式安全动作未经过来源核验的项目均不得臆造。

### 0.1 状态定义

- `SPECIFIED_DIRECTION`：系统能力或设计原则已存在批准来源，**不是硬件实现已完成**；
- `OPEN_EVIDENCE`：物理数据、市场/车型、器件或验证标准缺失；
- `BLOCKED_SAFETY`：危险分析及实体电路证据不足，不能批准功率设计/实物测试；
- `DESIGN_OPTION`：需进行真实方案权衡，未选择某个器件/拓扑；
- `VERIFIED`：应仅在对应实物/文件证据真正复核完成后使用，当前本文件**没有任何 VERIFIED 项**。

## 2. 尚需确定的产品硬件结构选项（此处不选定拓扑）

### 2.1 必须进行的设计权衡

| 决策 | 至少需要评价的方面 | 不可在此直接确定 |
|---|---|---|
| ECU/功率板集成与分离 | 强电/逻辑干扰、维修、更换、成本、温升、测点、线束和故障传播 | 必须单板或双板 |
| 独立/多通道轮端驱动 | 轮数、通道电流、差异检测、失效后方向稳定性和成本 | “只用一个PWM通道足够” |
| 控制器 MCU/存储资源 | 真实输入、CAN/UART/DMA、调试/生产、看门狗、失效监测、温度/生命周期成本 | EVB型号就是量产 MCU |
| 运动信息路径 | 外置 CAN 模块、板载 BMA510 或其他方案的准确度、安装、故障诊断和价格 | 两份传感器资料属于同一产品 |
| 通信/HMI | V2 LCD 独立按键及状态可见性、V3 BLE可选模块、车载EMC/安全 | V2必须依赖手机、V1必须有 BLE |
| 执行反馈 | 测电流、驱动状态、温度/回路诊断的真实可观测性、盲区及成本 | 无故障位=实际轮端制动力正确 |
| 电源/保护 | 目标供电、温度、浪涌、反接、复位及供电域隔离 | 用通用12V示例值直接当目标产品额定 |
| 安全默认态与独立抑制 | 上电/高阻/复位/程序卡死/器件短路的真实物理动作、故障覆盖、保护时序 | 只靠软件赋0或通用“全部关断”即安全 |

这些是产品 PCB 设计的比较项，属于明确的工程研究，而不是以“适度抽象”为由放松汽车软件与硬件质量要求。所有最终安全相关取舍必须有危险分析、设计计算及试验计划。

## 3. PCB 原理图开工准入矩阵

| 准入级别 | 允许开始的工作 | 不允许的越界 |
|---|---|---|
| P4-DESIGN-1 系统框图 | 物理接口集合、责任分配、危险场景、候选系统拓扑和测试要求 | 用没有规格的器件做功率定额、承诺最终车规适用 |
| P4-DESIGN-2 非功率接口原理图准备 | 在核对实际 MCU/模块/板图后比较输入、通信、调试与低压电源方案 | 将尚未确认的原理图引脚和传感方向作为已实现 |
| P4-DESIGN-3 功率原理图设计准入 | 必须有轮端/电源/线束规格、功能安全目标及功率风险评价；然后进行具体拓扑计算/评审 | 缺实体参数而让功率板“先设计以后再改” |
| P4-DESIGN-4 打样/受控实验准入 | 需设计评审、故障保护分析、样机装配/测点、实验夹具、限流/急停与隔离工况 | 直接让 EVB 驱动真实拖挂制动器或上路 |

> P4-DESIGN-1 可以继续进行。本文件**不等于** P4-DESIGN-2/3/4 已获准入，也不阻碍后续在负责人明确批准且证据充分的条件下并行开展不同功能的工作。
