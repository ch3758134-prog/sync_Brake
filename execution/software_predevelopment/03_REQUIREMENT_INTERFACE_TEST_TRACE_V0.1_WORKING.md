| INT-06 | 电源瞬变/复位 + 看门狗 + 维护/配置请求 | 服务模式和远端命令不能绕过设备启动资格 | 上电/掉电与硬件保护 |
| INT-07 | 多个故障同时激活 + 日志已满 | 不应丢失关键活动故障，仅清理记录不等于恢复 | 故障等级/容量/恢复 |
| INT-08 | 不匹配的 Board/Variant 配置 + 允许设备连接 | 通信成功不意味配置可生效或产品可运行 | 兼容矩阵和生产配置 |

这些场景是**设计讨论输入**；所有涉及真实输出的最终响应均须经过特定产品危险分析，不能用“测试预期”越权确定。
